Use the Arcane Privacy SDK in your frontend or backend to prepare private transactions. The SDK is available in TypeScript. Connect it to your wallet or server-side signer, Arcane's smart contracts, and the services for your environment.

## SDK

The SDK provides deposit, transfer, and withdrawal operations, input validation, and progress and error reporting.

| Your application | SDK integration | Continue |
| --- | --- | --- |
| Browser application | Browser runtime assets and a connected wallet | [Frontend integration](/application-development/setup) |
| Node.js service | Filesystem runtime assets and a server-side signer | [Backend integration](/integration/backend) |

React and Redux are used in the frontend setup example. The backend example runs the SDK in Node.js with server-side signing and account-scoped storage.

## Smart contracts

On Stellar, the SDK prepares calls to the Privacy Layer's Soroban contracts. The pool contract verifies and applies private transactions; the registry supports private recipient addressing. Your integration supplies the contract IDs and RPC configuration for its environment.

Read [How the Privacy Layer works](/products/privacy-layer/how-it-works) for the execution flow.

## Supporting APIs

Your integration also uses services for transaction submission and the data the SDK needs.

| Service | Purpose |
| --- | --- |
| [Relayer API](/products/privacy-layer/api-reference/relayer) | Submit eligible private operations and track their status |
| Data services | Load assets, recipient registry data, pool state, and encrypted note deliveries |
| [KYT API](/products/privacy-layer/api-reference/kyt) | Check transaction passages against the configured compliance rules |

The submission route depends on the operation. Use `requiredSubmissionMethod` with the pool's configuration nonce after preparing the operation. Direct operations use `execute()`; private-sender transfers and escrow sends use `@arcanetech/privacy-sdk-relay`. See [Transaction lifecycle](/concepts/operation-lifecycle#direct-submission-vs-protocol-relay).

See [State methods](/integration/data-sources) for the data your application provides.

## Compliance Platform APIs

Use the [Compliance Platform APIs](/products/compliance-platform/integration/api-reference/overview) to manage user-authorised and server-to-server compliance workflows. They are separate from the Privacy Layer's transaction execution services.
