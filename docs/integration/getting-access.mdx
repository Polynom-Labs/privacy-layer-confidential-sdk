Install from the public npm registry under `@arcanetech`. Anonymous `npm install` is enough for the published **0.5.x** line of `@arcanetech/privacy-sdk-stellar`. There is no extra GitHub Packages token in this path.

```bash
npm install @arcanetech/privacy-sdk-stellar @arcanetech/privacy-sdk-state-memory
```

React apps: [Install](/application-development/install) (`state-redux` + Relayer when you need a private sender or escrow send).

## What a live client needs

A Stellar **wallet** (Freighter or your adapter) only supplies a `G…` address and signatures. It does **not** supply pool IDs, KYT, Relayer, or tag issuance.

| You must have | What it is |
| --- | --- |
| `network.poolContract` | Soroban privacy pool (`C…`) |
| `network.registryContract` | Private-address registry (`C…`) |
| `network.applicationId` | Compliance `association.audit_id` — **decimal Fr string only**, not a UUID |
| `auditPublicKeyHex` | Application audit public key (128 hex or `04`+X+Y). Not the SDK demo key |
| `kyt.apiBaseUrl` | KYT / Passage HTTP API |
| `kyt.kytPassageRegistryContract` | KYT passage registry (`C…`) |
| `network.rpcUrl` / passphrase | Testnet defaults are public (`soroban-testnet.stellar.org`, SDF testnet passphrase) |
| `relayConfig.origin` | Relayer base URL. Required for **private sender** and **escrow send**. Unset origin never contacts a relayer; escrow then fails with `escrow_relay_unconfigured` |
| Tag issuance / storage origin (optional) | Stand-supplied base URL used for escrow note discovery after the recipient registers |

How-to pages use **tutorial fixtures**. Runnable demos ship live stand rows in `.env.example` — see [Quick start](/integration/quick-start). `execute()` will not confirm on testnet with how-to fixture IDs.

## Where partners get the values

1. Create or receive a **`stellar-pool` application** in the [Compliance Platform](/products/compliance-platform/user-guide/organisation-management/application-management). The platform issues the **decimal** application id (`association.audit_id`) and the public audit key. Private audit material stays server-side.
2. Take **pool, registry, KYT contract, KYT URL, Relayer origin**, and — when you need escrow discovery — a **tag-issuance / storage origin** from the stand Arcane gives you (or from your own deployment). Do not copy another product’s `.env` into a partner app unless that stand is explicitly yours.
3. Put them in your environment. Demo stands configure a Relayer origin; yours must come from your stand owner.

Side-by-side tutorial / frontend demo / backend demo IDs: [Data sources](/integration/data-sources#where-each-config-field-comes-from).

When `zkConfigNonce` is omitted, the SDK default is binding nonce **`3`** (bundled 2×2). Nonce **`7`** (bundled 6×6) is also shipped. Match the on-chain pool `ZkConfig` — a mismatch fails with `no zk circuit configured for nonce …`. Do not copy another stand’s nonce into a new integration unless that stand is the target.

## First live transaction

Deposit with a **public sender** and Direct Submission (`operation.execute()`). That path does not need Relayer. You still need a funded testnet wallet (or HD account) and the stand row above.

Fastest path: clone a demo — [Quick start](/integration/quick-start). Private sender, unregistered escrow send, and Relayer wiring are covered there and in the [withdraw](/application-development/how-to/withdraw) / [unregistered transfer](/application-development/how-to/transfer-unregistered-recipient) how-tos.
