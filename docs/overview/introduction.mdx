Use the Arcane Privacy SDK to deposit funds, send private transfers, and withdraw funds in your application. The SDK prepares transactions, validates operation inputs, and coordinates signing and submission to Arcane's smart contracts.

The SDK is currently available in TypeScript and can be used in JavaScript and TypeScript applications, in the browser or on a Node.js backend. The integration guides in this section cover Stellar and Soroban.
