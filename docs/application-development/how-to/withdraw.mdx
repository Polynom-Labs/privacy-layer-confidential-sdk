Withdraw spends a private pool note and pays out to a public wallet.

## Disclosure policy

<OperationDisclosures operation="withdraw" />

Sender may be public or **private**. Private sender requires **Protocol Relay** (zero public deposit). `operation.execute()` is Direct Submission only and does not contact the relayer.

After prepare, call `requiredSubmissionMethod(operation.prepared, zkConfigNonce)` from `@arcanetech/privacy-sdk-stellar/transact`. Use the nonce configured for your deployed pool:

- `direct` — `await operation.execute({})`
- `relay` — submit through `@arcanetech/privacy-sdk-relay`. Follow the port-wiring pattern in the [escrow transfer guide](/application-development/how-to/transfer-unregistered-recipient#run-operation) and the complete [reference applications](/integration/quick-start).

### Run operation

```tsx
import { requiredSubmissionMethod } from '@arcanetech/privacy-sdk-stellar/transact';

const operation = await client.withdraw({
  from: 'stpl1sender7exampleprivateaddress0000000000',
  to: 'GDSENDER7EXAMPLEPUBLICKEYAAAAAAAAAAAAAAAAAAAA',
  asset: 'usdc',
  amount: 40_0000000n,
  disclosure: {
    senderAddress: 'private',
    recipientAddress: 'public',
    assetAddress: 'public',
    amount: 'public',
  },
});

if (operation.status !== 'prepared') {
  throw new Error(operation.errors[0]?.message);
}

// Use the same environment passed when creating the client.
const zkConfigNonce = transactEnvironment.zkConfigNonce;
if (zkConfigNonce === undefined) {
  throw new Error('Configure the nonce for your deployed pool.');
}
const method = requiredSubmissionMethod(operation.prepared, zkConfigNonce);

if (method === 'direct') {
  await operation.execute({});
} else {
  // Replace this guard with your application's Relay submission.
  // Do not fall back to direct submission for a private sender.
  throw new Error('Connect the Relay submission flow before sending.');
}
```
