# Privacy Layer SDK

The Privacy Layer SDK provides a declarative API for privacy operations such as deposit, transfer, and withdraw.

## Packages

- `@arcane/privacy-sdk-core`: network-agnostic contracts and orchestration
- `@arcane/privacy-sdk-stellar`: Stellar preset built on top of the core package

`@arcane/privacy-sdk-testing` is planned but not published in the current phase.

## Design Principles

1. Users create operation intents instead of assembling proofs manually.
2. Preparation and execution are separate phases.
3. Only prepared operations expose `execute()`.
4. Core public types stay free of Stellar and ZK terminology.
