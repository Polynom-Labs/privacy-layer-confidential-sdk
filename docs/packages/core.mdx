# @arcane/privacy-sdk-core

The core package exports:

- disclosure policy types
- operation intents
- prepared and rejected operation results
- typed runtime errors
- progress events
- adapter contracts
- `PrivacyClient` and `AdapterPrivacyClient`

## Dependency Boundary

The core package must not depend on Stellar, Soroban, ZK, or `@auditable/privacy-pool-zk-sdk`.

## Typical Flow

1. Build an intent.
2. Call `client.deposit()`, `client.transfer()`, or `client.withdraw()`.
3. Handle `RejectedOperation.errors` or call `PreparedOperation.execute()`.
