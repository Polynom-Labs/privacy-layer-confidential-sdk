# @arcane/privacy-sdk-stellar

The Stellar package wraps the core contracts with:

- browser and Node entrypoints
- Stellar wallet, storage, and policy adapters
- disclosure validation for supported routes
- orchestration over `@auditable/privacy-pool-zk-sdk`

## Entrypoints

- `@arcane/privacy-sdk-stellar` — browser-first; pass preloaded `ArrayBuffer` assets
- `@arcane/privacy-sdk-stellar/node` — Node.js filesystem asset paths
- `@arcane/privacy-sdk-stellar/testing` — fake transact engines for unit tests

## Asset Requirements

Applications must provide circuit WASM and proving key artifacts. This repository does not generate `ptau` or Groth16 zkey files.
